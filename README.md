# Agent Vilde: Familiebureauet

A multiplication practice game in Danish, built as a family spy story.

> Work in progress. The full parent guide (Home Screen install, offline version, backups) arrives with the polish pass.

## Run it on your computer

The game must be served, not double-clicked. In this folder, run:

```
python -m http.server 8000
```

(On Mac/Linux use `python3`.) Then open http://localhost:8000.

- Game: http://localhost:8000/
- Engine test bench: http://localhost:8000/test.html
- Question card demo: http://localhost:8000/card.html

Engine tests also run from the command line: `node tests/run.js`
